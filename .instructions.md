# PMSR Module - Protected Directories

## 🚨 CRITICAL: READ-ONLY DIRECTORIES

The following directories contain **PROTECTED DATA** and **MUST NOT** be modified by Copilot unless the user **EXPLICITLY requests changes** to files in these specific directories:

### Protected Directories:
1. **`instructions/`** - User-facing instructions and documentation
2. **`kgrimages/`** - Knowledge graph images and resources  
3. **`mts/`** - Metadata template spreadsheets (Excel files)
4. **`prompts/`** - AI prompts and workflow generation templates

## Rules for Copilot:

### ❌ DO NOT:
- Create, modify, or delete any files in these protected directories
- Suggest changes to files in these directories
- Move files into or out of these directories
- Refactor code that references these directories
- Update file paths that point to these directories

### ✅ DO:
- **Only modify protected directories when the user explicitly says**: "change file X in `instructions/`" or "update the file in `mts/`" or similar clear directive
- Read from these directories when needed for context
- List files in these directories when asked
- Explain what files contain when asked
- Work freely on all other directories in the module (`src/`, `tests/`, `js/`, `css/`, config files, etc.)

## Example of Explicit Permission:
- ✅ "Update the INS-PMSR.xlsx file in the mts folder"
- ✅ "Change the Portuguese instructions in instructions/instructions_PT.md"
- ✅ "Add a new prompt to the prompts directory"

## Example of NO Permission:
- ❌ "Improve the module" (implicit, don't touch protected folders)
- ❌ "Refactor the code" (implicit, don't touch protected folders)
- ❌ "Fix all issues" (implicit, don't touch protected folders)

## Reason for Protection:
These directories contain:
- **Data ingestion templates** with complex Excel structures
- **User documentation** in multiple languages
- **AI prompts** carefully crafted for specific workflows
- **Binary resources** that should not be regenerated

Unintended modifications could break data ingestion pipelines, confuse users, or corrupt workflows.

---

**When in doubt, ask the user before modifying anything in these 4 directories.**
