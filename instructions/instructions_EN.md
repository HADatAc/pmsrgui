##### WKF Generation with ChatGPT - Instructions

1. **Generate WKF:**
   - Click the "Generation Prompt" button to open the generation prompt window
   - Click "Copy to Clipboard" to copy the prompt
   - Open ChatGPT (GPT-4 or later recommended)
   - Paste the generation prompt (CTRL-V or CMD-V)
   - Click the "+" button (attach) to add your document (PDF, Word, Excel, etc.)
   - Send the message and wait for the WKF generation
   - ChatGPT will generate an Excel WKF file structure for you
   - Download the generated Excel file

2. **Validate WKF:**
   - Click the "Validation Prompt" button to open the validation prompt window
   - Click "Copy to Clipboard" to copy the prompt
   - In ChatGPT, paste the validation prompt (CTRL-V or CMD-V)
   - Click the "+" button (attach) to upload the WKF file generated in the previous step
   - Send the message for validation
   - ChatGPT will check for errors and suggest corrections
   - If there are errors, ask ChatGPT to fix the WKF and make it available for download
   - Download the corrected WKF file

3. **Download Ontologies:**
   - Click "Download Ontologies" to obtain the necessary ontology files
   - These ontologies provide the valid terms and structure for your WKF

4. **Upload and Ingest WKF:**
   - Click the "Add New WKF" button below
   - Fill in the WKF name and details
   - Upload your validated Excel file
   - Save the WKF
   - Select your WKF from the table
   - Click "Ingest WKF Selected as Draft" to test, or "Ingest WKF selected as Current" for production
   - Check the "Log" column for any ingestion errors
