##### Geração de WKF com ChatGPT - Instruções

1. **Gerar WKF:**
   - Clique no botão "Generation Prompt" para abrir a janela com o prompt de geração
   - Clique em "Copy to Clipboard" para copiar o prompt
   - Abra o ChatGPT (GPT-4 ou posterior recomendado)
   - Cole o prompt de geração (CTRL-V ou CMD-V)
   - Clique no botão "+" (anexar) para adicionar o seu documento (PDF, Word, Excel, etc.)
   - Envie a mensagem e aguarde a geração do WKF
   - O ChatGPT irá gerar uma estrutura de arquivo Excel WKF para você
   - Descarregue o arquivo Excel gerado

2. **Validar WKF:**
   - Clique no botão "Validation Prompt" para abrir a janela com o prompt de validação
   - Clique em "Copy to Clipboard" para copiar o prompt
   - No ChatGPT, cole o prompt de validação (CTRL-V ou CMD-V)
   - Clique no botão "+" (anexar) para carregar o arquivo WKF gerado no passo anterior
   - Envie a mensagem para validação
   - O ChatGPT verificará erros e sugerirá correções
   - Se houver erros, peça ao ChatGPT para corrigir o WKF e disponibilizar como download
   - Descarregue o arquivo WKF corrigido

3. **Descarregar Ontologias:**
   - Clique em "Download Ontologies" para obter os arquivos de ontologia necessários
   - Estas ontologias fornecem os termos e estrutura válidos para o seu WKF

4. **Carregar e Ingerir WKF:**
   - Clique no botão "Add New WKF" abaixo
   - Preencha o nome e detalhes do WKF
   - Carregue o seu arquivo Excel validado
   - Guarde o WKF
   - Selecione o seu WKF da tabela
   - Clique em "Ingest WKF Selected as Draft" para testar, ou "Ingest WKF selected as Current" para produção
   - Verifique a coluna "Log" para quaisquer erros de ingestão
